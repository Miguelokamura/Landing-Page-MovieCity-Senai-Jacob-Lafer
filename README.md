# MovieCity

Landing page responsiva para explorar uma seleção de filmes, feita com React e Vite.

## Como executar

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` inicia o servidor local do Vite.
- `npm run lint` verifica o código com ESLint.
- `npm run build` gera a versão de produção em `dist/`.
- `npm run preview` abre uma prévia da versão de produção.

Os pôsteres usados pela página estão em `src/assets/`.
